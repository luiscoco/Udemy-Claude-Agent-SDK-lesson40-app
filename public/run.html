Configure and run the app.

Install the SDK, configure your key and run the classroom comparisons.

01

Prerequisites

Use Node.js 24+, Git, model API access and available credit. Windows may require Git Bash. Python is needed only to regenerate student pages.

node --version
git --version
npm --version
02

Install and configure .env

Install dependencies. Preserve an existing .env and enter your own API key privately. Never commit the real file.

cd .\agent-sdk\lesson40-forking
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start and navigate

Keep the terminal running and open the five student pages. If the port is occupied, change PORT and restart.

npm start
# http://127.0.0.1:3140
04

Fork and compare

Run Basic, Compare and Independent. Compare native init/result IDs and responses. Original JWT-40 and fork OAUTH-40 are classroom labels only. In Choice inspect either actual transcript, select a branch, then click Resume selected session.

npm run sample:env -- basic
npm run sample:env -- compare
npm run sample:env -- independent
npm run sample:env -- choice
05

Check file isolation

Shared-files writes the same lesson.txt and the original performs a NEW Read. Worktrees repeats the test with an actual separate Git worktree. Compare main and branch markers. Only the fixed classroom fixture can be written.

npm run sample:env -- shared-files
npm run sample:env -- worktrees
06

Compare state transfer strategies

Transfer copies the real JSONL into another LOCAL SDK configuration and resumes the same ID. State supplies explicit JSON app state to a fresh target session. No-fork shows a plain resume changing the original. CLI Choice automatically selects the fork; the web requires your click.

npm run sample:env -- transfer
npm run sample:env -- state
npm run sample:env -- no-fork
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3140
# Windows only, if needed:
# CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Only your model key is required. Keep it local and restart after edits. Existing shell variables take precedence.

Troubleshooting

Use Node 24+, API credit and a supported model. Configure Git Bash on Windows if requested. If the port is occupied, use the printed existing-app URL or change PORT. In Resume wait for the actual catalog, inspect a transcript and click Resume selected session. Other modes finish automatically. Selection expires after two minutes. Change PORT if 3140 is occupied.
